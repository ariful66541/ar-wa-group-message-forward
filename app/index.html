About this software

AR WA — Group Message Forward is a smart WhatsApp message forwarding software. It reads new messages from the source groups you choose and sends the same text, unchanged, to every target group you choose.

  • The message goes out exactly as received — no added text, no prefix, no change to emoji, numbers or line breaks.
  • Images, PDFs, videos, audio and stickers are never forwarded — text only.
  • Any number of source groups and target groups.
  • Forwarding runs only inside the daily schedule window (09:50 – 16:28 by default).
  • Auto scheduled messages: write a message once, pick the groups, the time and the repeat, then press Start.
  • Everything runs inside this window — no Chrome, no ChromeDriver, nothing extra to install.
  • The software is password protected, and asks for the password every time it opens.
